How this demo works

Bring your own agent. This page registers shop tools on document.modelContext (WebMCP). Paste the URL into Grok, Claude, ChatGPT, or anything that can call page tools. There is no store chatbot to learn.

GitHub Pages loads the official polyfill from GoogleChromeLabs/webmcp-tools (it no-ops if native document.modelContext exists). Native Chrome still wants chrome://flags/#enable-webmcp-testing (origin trial from 149). The Agent panel uses document.modelContext.getTools + executeTool (Page Agent pattern, no Gemini key) to call the same seven tools: list_products, get_product, add_to_cart, get_cart, checkout, buy_item, get_shop_status.

Stock is shared. A buy from any agent (or a POST to the Worker) updates every open shop tab within about two seconds. Sold-out SKUs restock on the server after 20–45s. Agent responses include tell_your_human so the agent taps its owner.
